Publish
Publishing needs a GitHub fine-grained token with access to aenariel/KSDailyAgenda only and the permission Contents: Read and write (github.com → Settings → Developer settings → Fine-grained tokens). It is only sent to GitHub.
Without a token: download the file, then on GitHub open events.json → ✏️ (or "Add file → Upload files") and commit it.
